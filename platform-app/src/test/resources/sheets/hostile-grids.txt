@@ The corpus of hostile grids (Functional track FA3, ADR-0173 section 4, ADR-0186).
@@
@@ One construct per line, four fields separated by a TAB:
@@   1. the code of the FIRST problem the validator must answer with;
@@   2. how the document is made: "merge" (a JSON merge patch applied to the smallest valid document: a key set to null
@@      is removed, an object is merged key by key, anything else, an array included, replaces), "raw" (the payload is
@@      the whole text of the document) or "gen" (the payload names a generator in SheetHostileCorpusTest);
@@   3. the payload;
@@   4. why the construct is hostile.
@@ The smallest valid document has two columns (c1 a text, c2 a number), one header row h1 and one row r1.
@@ Every line must be refused with that code and with places and words that never repeat what was typed: the marker
@@ HOSTILEMARK and markup must not come back (SheetHostileCorpusTest). A line that starts with two at signs is a
@@ comment. To add a line: write it and run the test; to see that the test can fail, follow
@@ "Sprint FA3 manual testing.md".
@@
