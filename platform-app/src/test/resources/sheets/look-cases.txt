# SH4, ADR-0251 (note "Built in SH4"). The one file of look cases that BOTH sides read: the Java tests (server) and the TypeScript
# tests (browser). It holds no text of a real form. The expected values are the DOCUMENTED behaviour of a spreadsheet program for the
# format code the file out writes (NumberFormats.codeOf), written before the browser's formatter existed. A new key, operator or
# format needs cases here, in the browser's code, and a line in the Java test.
#
# [number]     key | kind | value | expected
#              kind: number | text | boolean | error | blank. A value is shown as the server gives it (plain digits, at most fifteen
#              significant, possibly with an exponent). Locale: a dot for decimals and a comma for thousands, whatever the browser says.
#              Only the rows of kind "number" are also held to the library's formatter by the Java test (accounting excepted: the
#              library does not draw the padding and the dash of that format; see the test).
# [condition]  operator | value | value2 | cell | expected      (expected: yes or no; cell is the displayed number, "text" for text)
# [words]      operator | value | value2 | the fixed words a screen reader gets
# [ink]        fill (six hex digits, no hash sign) | the ink chosen for a cell with that fill and no text colour (dark or light)
