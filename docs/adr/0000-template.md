# ADR-NNNN: Title in the form of a decision

- **Status:** Proposed | Accepted | Superseded by ADR-NNNN | Rejected
- **Date:** YYYY-MM-DD
- **Decision IDs:** (for example D1; leave out if none)
- **Sprint:** the sprint in which this was decided

## Context

What forces are at play? What problem needs a decision, and what constraints (technical, product, team)
apply? State facts, not the solution.

## Decision

The decision, in the active voice ("We will ..."). Be specific enough that someone can check the code
against it.

## Consequences

What becomes easier, what becomes harder, what new rules follow, what must be revisited and when.
Include how the decision is enforced (an automated test is better than a convention).

## Alternatives considered

Each serious alternative with the reason it was not chosen.

## References

Links to the delivery plan, other ADRs, spikes and code locations (file paths).
